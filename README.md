# SlipCurve sample projects

Test projects for [SlipCurve](https://gostrogis.github.io/SLIPCURVE/). Its **Sample
projects** dialog downloads a project's files from here only when it is opened.

Generated by `tools/samples.py` in the SlipCurve repository. Do not edit by hand:
each file is pinned to its SHA-256 and the app refuses a file that differs.
